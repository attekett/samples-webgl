# WebGL corpus tooling handoff (2026-10-17)

The deployable fuzzing input is [`agent_outputs/mutator_baseline/core/`](../agent_outputs/mutator_baseline/core/) for Firefox or Chrome. Add [`agent_outputs/mutator_baseline/chrome_extensions/`](../agent_outputs/mutator_baseline/chrome_extensions/) only for Chrome/ANGLE-Vulkan. These directories contain symlinks to canonical HTML seeds: 12 core seeds and 2 Chrome extension seeds. The original seven core seeds expose all 25 current valid-flow mutator families; their browser and mutation checks are recorded in the [baseline report](2026-10-16-webgl-mutator-corpus-baseline.md).

The coverage tooling is `scripts/corpus_metrics.py`, with trace, reducer, static coverage, and value classification support in `scripts/api_audit/`. Its [usage and evidence](webgl_corpus_metrics.md) include full Chrome and Firefox control profiles, Grizzly calibration for the current baseline, and equal-time adoption comparisons. The coverage snapshots under `docs/snapshots/` are reports, not driver coverage claims. Browser configuration for the Chrome extension lane is [`config/angle_vulkan.json`](../config/angle_vulkan.json).

Six additional seeds in `agent_outputs/` cover uniform buffers, transform feedback, occlusion queries, sampler objects, buffer/value boundaries, and the remaining `WEBGL_multi_draw` methods. Their target-browser controls pass, adding 72 measured requirements in Chrome and 73 in Firefox. Their 12-second equal-time campaigns reduced clean mutation yield. The 300-second campaigns and Grizzly calibration on 2026-10-17 passed the adoption gate in Chrome; Firefox fell 8 clean variants short, inside run-to-run spread. They were added to the active baseline. Details are in the [shortlist results](webgl_corpus_metrics.md#shortlist-additions-2026-10-16) and the [300-second comparison](webgl_corpus_metrics.md#300-second-comparison-and-calibration-2026-10-17).

Validation before handoff: `python -m pytest -q scripts/tests scripts/api_audit/tests` passed **447 tests**. The ordinary runner reports for all six new seeds have `passed: true`, completion, and empty console, JavaScript, WebGL, error, and warning arrays. The profiler reports show 14/14 clean Chrome controls and 12/12 clean Firefox controls in the expanded set. `git diff --check` passed.

Integration with the local `master` branch passed **568 tests**. The merge retained both sets of `CLAUDE.md` commands and regenerated the API surface with 226 methods, 56 extensions, and numeric WebGL versions. Firefox passed the typed-view baseline smoke test; Chrome/ANGLE-Vulkan passed the indexed and instanced multi-draw smoke test.

For a production campaign, use the baseline and record the exact browser executable, renderer, seed hashes, campaign time, and output ledger. On a different target machine, repeat the equal-time comparison and calibration there. No GitHub push is part of this handoff; the repository remote is SSH and must not be used by agents.

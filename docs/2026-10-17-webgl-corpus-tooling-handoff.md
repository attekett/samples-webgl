# WebGL corpus tooling handoff (2026-10-17)

The deployable fuzzing input is [`agent_outputs/mutator_baseline/core/`](../agent_outputs/mutator_baseline/core/) for Firefox or Chrome. Add [`agent_outputs/mutator_baseline/chrome_extensions/`](../agent_outputs/mutator_baseline/chrome_extensions/) only for Chrome/ANGLE-Vulkan. These directories contain symlinks to canonical HTML seeds. The seven core seeds expose all 25 current valid-flow mutator families; their browser and mutation checks are recorded in the [baseline report](2026-10-16-webgl-mutator-corpus-baseline.md).

The coverage tooling is `scripts/corpus_metrics.py`, with trace, reducer, static coverage, and value classification support in `scripts/api_audit/`. Its [usage and evidence](webgl_corpus_metrics.md) include full Chrome and Firefox control profiles, Grizzly calibration for the current baseline, and equal-time adoption comparisons. The coverage snapshots under `docs/snapshots/` are reports, not driver coverage claims. Browser configuration for the Chrome extension lane is [`config/angle_vulkan.json`](../config/angle_vulkan.json).

Six additional seeds in `agent_outputs/` cover uniform buffers, transform feedback, occlusion queries, sampler objects, buffer/value boundaries, and the remaining `WEBGL_multi_draw` methods. Their target-browser controls pass, adding 72 measured requirements in Chrome and 73 in Firefox. They are available for targeted runs. They are not in the active baseline because 12-second equal-time campaigns reduced clean mutation yield; they have not received Grizzly calibration. Details and links are in the [shortlist results](webgl_corpus_metrics.md#shortlist-additions-2026-10-16).

Validation before handoff: `python -m pytest -q scripts/tests scripts/api_audit/tests` passed **447 tests**. The ordinary runner reports for all six new seeds have `passed: true`, completion, and empty console, JavaScript, WebGL, error, and warning arrays. The profiler reports show 14/14 clean Chrome controls and 12/12 clean Firefox controls in the expanded set. `git diff --check` passed.

For a production campaign, use the existing baseline and record the exact browser executable, renderer, seed hashes, campaign time, and output ledger. Reconsider adding the six candidates only after a longer equal-time comparison and calibration on the target machine. No GitHub push is part of this handoff; the repository remote is SSH and must not be used by agents.

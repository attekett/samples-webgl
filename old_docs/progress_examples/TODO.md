# AMD GPU WebGPU Demo Showcases

## Goal
Create standalone HTML demo files that showcase WebGPU capabilities running on AMD GPU hardware. Each demo should demonstrate real-world use cases leveraging the WebGPU API's features while staying within the portable specification limits.

## CRITICAL: Understanding WebGPU vs Vulkan

**IMPORTANT:** The `webgpu_details.txt` file contains **Vulkan driver capabilities** from the underlying AMD GPU. WebGPU is a **web API** that only exposes a **portable subset** of features available across all platforms (Windows/Linux/Mac, AMD/NVIDIA/Intel/Apple).

### Features NOT Available in WebGPU:
- ❌ Geometry Shaders (`geometryShader`)
- ❌ Tessellation Shaders (`tessellationShader`) 
- ❌ Mesh Shaders (`VK_EXT_mesh_shader`)
- ❌ Ray Tracing (`VK_KHR_ray_tracing_*`)
- ❌ Compute Shader Derivatives (`VK_KHR_compute_shader_derivatives`)
- ❌ Sparse Textures (`sparseResidency*`)
- ❌ AMD-specific extensions (`VK_AMD_*`)
- ❌ Multi-viewport rendering (`multiViewport`)

### Features AVAILABLE in WebGPU:
- ✅ Compute shaders with workgroup operations
- ✅ Storage buffers and storage textures
- ✅ Indirect drawing and compute dispatch
- ✅ Timestamp queries (with feature)
- ✅ Multiple render targets (up to 8 on this GPU)
- ✅ Atomic operations in compute shaders
- ✅ Texture compression (BC, with feature)
- ✅ 64-bit integer atomics (limited support)

Reference: [WebGPU W3C Specification](https://www.w3.org/TR/webgpu/)

## WebGPU Demo Showcase List

Based on **actual WebGPU capabilities** and the AMD GPU's underlying hardware performance, here are realistic demos:

## 1. Compute-Based Particle Explosion
**WebGPU Features:**
- Compute shaders with workgroup coordination
- Storage buffers for particle data (position, velocity, life)
- `maxComputeWorkGroupInvocations: 1024` - Large workgroups
- `maxComputeSharedMemorySize: 65536` - Shared memory for physics
- Multiple render passes (compute → render)

**Demo Concept:** GPU-driven particle system where compute shaders simulate thousands of particles with physics (gravity, collision), then render them as point sprites with color based on velocity.

## 2. Procedural Terrain with Compute Generation
**WebGPU Features:**
- Compute shader procedural generation
- Storage texture writes
- Indirect drawing (vertex buffer generated by compute)
- `maxStorageTexturesPerShaderStage: 8` - Multiple storage outputs
- Texture sampling with mipmaps

**Demo Concept:** Compute shader generates heightmap into storage texture, then uses indirect draw to render tessellated terrain mesh with LOD based on distance.

## 3. Multi-Pass Deferred Rendering
**WebGPU Features:**
- Multiple render targets (`maxColorAttachments: 8`)
- G-buffer (albedo, normal, depth, roughness)
- Storage textures for compute lighting pass
- Fullscreen post-processing

**Demo Concept:** Classic deferred rendering with geometry pass writing to 4 render targets, then compute shader performs lighting, followed by tone mapping and bloom.

## 4. Compute Shader Image Processing Pipeline
**WebGPU Features:**
- Compute shaders with image filters
- Storage texture read/write
- Workgroup shared memory for tile-based processing
- Multiple compute passes (blur, sharpen, edge detect)
- `maxComputeSharedMemorySize: 65536` for efficient tile loads

**Demo Concept:** Real-time image effects chain: Gaussian blur → edge detection → color grading, all in compute shaders visualizing intermediate steps.

## 5. Atomic Counter-Based Effects
**WebGPU Features:**
- Atomic operations in compute shaders
- `fragmentStoresAndAtomics: true` available on AMD
- Storage buffer atomics for global counters
- Histogram generation

**Demo Concept:** GPU histogram computation using atomics, then visualization. Also demonstrates order-independent transparency using atomic counters.

## 6. Indirect Multi-Draw Rendering
**WebGPU Features:**
- `drawIndirect` and `drawIndexedIndirect`
- GPU-driven culling in compute shader
- Indirect buffer generation
- `maxDrawIndirectCount` - Unlimited on AMD

**Demo Concept:** GPU frustum culling where compute shader tests thousands of objects and writes indirect draw commands, then renders visible objects in one call.

## 7. Timestamp Query Performance Profiling
**WebGPU Features:**
- Timestamp queries (if `timestamp-query` feature available)
- `timestampComputeAndGraphics: true` on AMD
- Query set creation and readback
- Multiple pipeline stages timing

**Demo Concept:** Complex scene with compute preprocessing, multiple render passes, visualizing GPU time for each stage with on-screen performance bars.

## 8. Storage Texture Feedback Loop
**WebGPU Features:**
- Storage texture write in compute
- Texture sampling in render pass
- Ping-pong buffers for temporal effects
- `maxStorageTexturesPerShaderStage: 8`

**Demo Concept:** GPU-based fluid simulation or Game of Life using compute shaders writing to storage textures, with render pass visualizing results.

## 9. Maximum Vertex Throughput Stress Test
**WebGPU Features:**
- Large vertex buffers
- `maxVertexBuffers: 32` on AMD
- `maxVertexAttributes: 32` on AMD
- Multiple vertex buffer bindings
- Instanced rendering

**Demo Concept:** Stress test rendering millions of vertices with complex vertex shader transformations, demonstrating AMD GPU vertex throughput capabilities.

## 10. Texture Compression Showcase
**WebGPU Features:**
- BC texture compression (if `texture-compression-bc` feature)
- `textureCompressionBC: true` available on AMD
- Multiple compressed formats (BC1, BC3, BC7)
- Memory efficiency comparison

**Demo Concept:** Side-by-side comparison of compressed vs uncompressed textures, showing quality and memory usage for BC1/BC3/BC7 formats.

## 11. Render Bundle Performance Showcase
**WebGPU Features:**
- Render bundles for command reuse
- Multiple bundle execution in single pass
- Bundle encoder with multiple pipelines
- Pipeline state caching across frames
- `maxColorAttachments: 8` - Record complex scenes

**Demo Concept:** Record complex scene with hundreds of objects into multiple render bundles, then execute repeatedly across frames. Visualize performance difference between bundles vs direct encoding.

## 12. External Texture Video Processing
**WebGPU Features:**
- `importExternalTexture()` from Canvas/Video
- External texture sampling in shaders
- YUV to RGB conversion (automatic in WebGPU)
- Frame-by-frame processing
- Integration with HTMLVideoElement/Canvas2D

**Demo Concept:** Import procedurally generated canvas as external texture, apply compute shader effects (color grading, distortion), render to WebGPU canvas showing real-time processing.

## 13. Multisampling Anti-Aliasing Pipeline
**WebGPU Features:**
- MSAA render targets (2x, 4x, 8x samples)
- `sampledImageColorSampleCounts: 15` - All sample counts supported
- Resolve operations to single-sampled texture
- Depth/stencil multisampling
- Sample mask and per-sample operations

**Demo Concept:** Render complex geometry at different MSAA levels (1x, 2x, 4x, 8x) with side-by-side comparison. Use sample mask for special effects.

## 14. Depth-Stencil Complex Operations
**WebGPU Features:**
- Depth testing with various compare functions
- Stencil operations (reference, mask, compare, ops)
- `depth32float` and `depth24plus-stencil8` formats
- Depth bias for shadow rendering
- Read-only depth/stencil attachments

**Demo Concept:** Multi-layer scene using stencil for portal effects or outline rendering. Visualize depth buffer and stencil states with color mapping.

## 15. Massive Instancing Showcase
**WebGPU Features:**
- Instanced drawing with 100,000+ instances
- Per-instance vertex attributes
- `maxVertexAttributes: 32` - Multiple instance streams
- GPU-side instance transform generation
- Indirect instanced drawing

**Demo Concept:** Render massive forest/city using instancing. Compute shader generates per-instance transforms, then draw with `drawIndirect` using instance counts.

## 16. Dynamic Uniform Buffer System
**WebGPU Features:**
- Dynamic uniform buffer offsets
- `maxUniformBufferBindingSize` - Large uniform buffers
- `maxUniformBufferBindingSize: 4GB` on AMD
- Multiple bind groups with dynamic offsets
- Efficient material/object switching

**Demo Concept:** Scene with many materials sharing uniform buffer. Use dynamic offsets to switch materials without rebinding. Visualize different lighting/materials on objects.

## 17. Blend Mode Gallery
**WebGPU Features:**
- All blend operations (add, subtract, min, max)
- Blend factors (src-alpha, one-minus, constant)
- Dual-source blending (`maxFragmentDualSrcAttachments: 1`)
- `dualSrcBlend: true` on AMD
- Alpha blending variations

**Demo Concept:** Visual gallery of blend modes applied to overlapping shapes. Show additive particles, alpha compositing, multiply effects, subtractive blending.

## 18. Texture Array and 3D Texture Sampling
**WebGPU Features:**
- 2D texture arrays (`maxImageArrayLayers: 2048`)
- 3D textures (`maxImageDimension3D: 2048`)
- Array indexing in shaders
- 3D texture trilinear sampling
- Cube texture arrays (`imageCubeArray: true`)

**Demo Concept:** Render slices through 3D texture (volume visualization), use texture arrays for animated sprites, and showcase cube map arrays for environment mapping.

## 19. Compute Shader Prefix Sum Algorithm
**WebGPU Features:**
- Workgroup shared memory with barriers
- `maxComputeSharedMemorySize: 65536` - Large shared memory
- Multi-pass reduction algorithms
- Workgroup synchronization
- Efficient parallel scan patterns

**Demo Concept:** Implement parallel prefix sum using compute shaders with workgroup coordination. Visualize scan steps. Use for particle sorting or stream compaction demo.

## 20. Large Texture Streaming and Mipmapping
**WebGPU Features:**
- Maximum texture size (`maxImageDimension2D: 16384`)
- Automatic mipmap generation
- LOD bias and selection in shaders
- `samplerAnisotropy: true` - Anisotropic filtering
- `maxSamplerAnisotropy: 16` on AMD

**Demo Concept:** Display huge 8192x8192 texture with mipmaps. Show LOD levels selected by distance. Demonstrate anisotropic filtering quality with oblique viewing angles.

## 21. Occlusion Query Culling System
**WebGPU Features:**
- Occlusion queries (`GPUQueryType.occlusion`)
- `occlusionQueryPrecise: true` on AMD - Exact sample counts
- Query sets and query results
- Binary occlusion (any samples passed)
- GPU-driven visibility determination
- Multi-pass rendering (occlusion → visible)

**Demo Concept:** Scene with hundreds of objects where first pass renders bounding boxes with occlusion queries, readback determines visibility, second pass renders only visible objects in full detail. Visualize occluded (red) vs visible (green) objects with on-screen stats showing culling efficiency.

**Implementation Details:**
- Create query set with one query per object
- Pass 1: Render low-poly bounding boxes with occlusion queries enabled
- Resolve queries to buffer and read back results
- Pass 2: Render only objects that passed occlusion test
- Display real-time stats: Total objects, Occluded, Visible, Culling %
- Use color coding: Red tint for occluded, green for visible objects
